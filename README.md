# Түгел — учёт посещаемости (Telegram Mini App)

Тема: «Студенттердің сабаққа қатысуын есепке алуға арналған Telegram Mini App әзірлеу және қатысу деректерінің дерекқорын құру».

Преподаватель открывает Mini App, проводит перекличку и отмечает каждого студента: есть, нет, опоздал, болеет, уважительная причина. Деканат видит, кого и сколько нет, и может приказом освободить студентов от занятий — тогда преподаватель сразу видит причину отсутствия во время переклички.

## Стек

| Слой | Технологии |
| --- | --- |
| Фронтенд | Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, three.js, SWR |
| Бэкенд | Next.js Route Handlers (`app/api/[...path]`), Node.js 24 |
| База данных | PostgreSQL (Neon), драйвер `pg`, схема в `db/schema.sql` |
| Telegram | `telegram-web-app.js`, проверка подписи `initData` (HMAC-SHA256), бот через вебхук |
| Хостинг | Vercel (регион fra1) |

Рабочая версия: https://tugel-attendance.vercel.app, бот — [@StudentReasershBot](https://t.me/StudentReasershBot).

## Запуск локально

```bash
npm install
cp .env.example .env.local   # заполните DATABASE_URL
npm run db:setup             # создаёт таблицы и демо-данные (если база пустая)
npm run dev                  # http://localhost:3000
```

`npm run db:reset` очищает все таблицы и загружает демо-данные заново (4 группы, 97 студентов, расписание, 4 недели посещаемости, приказы).

В демо-режиме (`DEMO_MODE=1`) на экране входа можно выбрать роль. Быстрый вход по ссылке: `/?demo=1` — преподаватель, `/?demo=6` — деканат.

## Деплой и Telegram

1. База: проект в [Neon](https://neon.tech), строка подключения — в `DATABASE_URL`.
2. Бот: токен от [@BotFather](https://t.me/BotFather) — в `BOT_TOKEN`.
3. Переменные `BOT_TOKEN`, `DATABASE_URL`, `DEMO_MODE` добавляются в проект Vercel, затем `npx vercel deploy --prod`.
4. Вебхук бота указывает на `/api/telegram/webhook` (метод `setWebhook` с `secret_token`), кнопка меню открывает приложение.
5. Бот отвечает на `/start` кнопкой открытия приложения и на `/id` — номером Telegram ID.

Чтобы аккаунт получил роль «Деканат» при входе через Telegram, укажите его ID в `ADMIN_TELEGRAM_ID`. Остальных сотрудников деканат добавляет в разделе «Қызметкерлер». Для боевого режима поставьте `DEMO_MODE=0` — тогда вход возможен только через Telegram.

## Роли

**Преподаватель**
- занятия на выбранный день из расписания;
- перекличка: «есть» / «нет» одним нажатием, остальные статусы и примечание — в выдвижной панели;
- кнопка «Қалғаны түгел» отмечает всех неотмеченных присутствующими;
- студент с действующим приказом выделен, указаны номер приказа, причина и срок.

**Деканат**
- обзор дня: сколько студентов отсутствует, разбивка по статусам и группам, список отсутствующих с причинами;
- статистика посещаемости по группам и студентам за 7 / 30 / 90 дней;
- приказы: освобождение одного или нескольких студентов на период, отмена приказа;
- сотрудники: добавление преподавателей и привязка Telegram ID.

Если приказ издан после переклички, отметки «нет» за этот период автоматически становятся «освобождён»; при отмене приказа они возвращаются обратно.

## База данных

| Таблица | Назначение |
| --- | --- |
| `users` | сотрудники: преподаватели и деканат, привязка к Telegram |
| `groups`, `students` | учебные группы и студенты |
| `subjects` | дисциплины |
| `timetable` | недельное расписание (шаблон) |
| `lessons` | конкретные занятия по датам, создаются из расписания |
| `attendance` | отметки посещаемости: одно занятие — один студент — одна запись |
| `exemptions` | приказы об освобождении от занятий |
| `v_attendance` | представление для отчётов |

Статусы: `present`, `absent`, `late`, `sick`, `excused`, `exempt`. Освобождённые занятия не снижают процент посещаемости.
